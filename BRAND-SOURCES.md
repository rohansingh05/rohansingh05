# Brand source notes

This package keeps the SVGs network-free by embedding small inline vector marks.

- GitHub, LinkedIn and Instagram: compact path geometry based on the corresponding Simple Icons / brand marks, rendered inline so no external asset request is needed.
- LeetCode and Codeforces: labeled monograms (`LC`, `CF`) are used instead of an invented or potentially incorrect logo silhouette.
- Simple Icons repository reference: https://github.com/simple-icons/simple-icons
- Simple Icons is distributed under CC0-1.0, subject to its legal disclaimer and the trademarks of the respective brand owners.

The README SVGs do not request brand assets from a CDN at render time.
