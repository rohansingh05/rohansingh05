## Asset notes

- `assets/id.png` is the supplied portrait, preserved as-is with its alpha channel.
- `assets/right_pointing.png` is the supplied pointing character, preserved as-is with its alpha channel.
- The five README-facing SVGs are fully self-contained: inline PNGs, inline WOFF2 fonts, CSS + SMIL only, and no network-loaded assets.
- The `*-static.svg` files are animation-free fallbacks used by the preview harness.
- Brand marks shown in `connect.svg` use compact inline vectors for GitHub, LinkedIn and Instagram; LeetCode and Codeforces use labeled monograms rather than an invented brand silhouette.
- No contribution-city section is included.

## Verification

`preview.html` contains the five animated SVGs as `<img>` elements plus animation-free fallbacks. The `previews/` directory contains snapshots at 0s, 2s, 5s, 9s and 13s for every animated SVG and static renders for each fallback. Links are syntactically checked against the supplied URLs, SVGs are checked for forbidden JavaScript/foreignObject/external image/font references, and alpha preservation is checked on both supplied PNGs.

### Upload these files

- `assets/hero.svg?v=1`

- `assets/stack.svg?v=1`
- `assets/id-dashboard.svg?v=1`
- `assets/connect.svg?v=1`

Keep `assets/id.png`, `assets/right_pointing.png`, `vendor/`, `previews/`, `preview.html`, and the license files in the package so the project remains auditable and self-contained.
